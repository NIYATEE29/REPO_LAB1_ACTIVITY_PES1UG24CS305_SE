# Community Lost & Found Matching Network - SE Lab 1

## Overview
This repository contains the deliverables for Lab 1: Requirements Engineering & UML Use-Case Modelling[cite: 1]. The proposed system is a lost-and-found community network that extracts visual and text item tags, runs geo-proximity matching between lost and found items, and requires proof-of-ownership question verification[cite: 2].

## Target Stakeholders / Actors
* Finder / Owner
* Community Admin

## Repository Contents
This repository includes the following deliverables:

* **Requirements Table:** A structured document containing exactly 5 Functional Requirements (FRs) and 2 Non-Functional Requirements (NFRs)[cite: 2]. Each requirement includes an ID, Type, Description, Priority, Acceptance Criteria, and Rationale[cite: 2].
* **UML Use-Case Diagram:** A PDF model illustrating all actors and primary use cases, including at least one `<<include>>` and one `<<extend>>` relationship[cite: 1, 2].
* **Use-Case Flow Specification:** A 1-page document detailing the Preconditions, Postconditions, Main Success Scenario, and one Alternate Flow for a core use case[cite: 2]. 

## Tools Used
* Online UML tools (e.g., Draw.io, LucidChart)
